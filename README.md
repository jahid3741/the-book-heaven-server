# The Book Heaven - Client Side

## Project Overview

The Book Heaven is a full-stack book management web application where users can register, login, add books, update books, delete books, review books, and explore books added by other users.

Users can:

- Register and Login with Firebase Authentication
- Add books
- Update their own books
- Delete their own books
- View all books
- View detailed information of each book
- Add reviews/comments
- Switch between dark and light theme

# Environment Variables

Create a `.env.local` file and add:

```env
VITE_apiKey=your_key
VITE_authDomain=your_domain
VITE_projectId=your_project_id
VITE_storageBucket=your_bucket
VITE_messagingSenderId=your_sender_id
VITE_appId=your_app_id
```
